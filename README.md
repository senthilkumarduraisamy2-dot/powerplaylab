# PowerPlay Lab Website

Static website for PowerPlay Lab, Texvalley, Erode.

Contact: +91 97866 89292 | hello@powerplaylab.in

## Files
- `index.html` — main website
- `css/style.css` — styling and responsive layout
- `js/script.js` — mobile navigation and small interactions
- `images/zones/` — zone photos
- `images/gallery/` — gallery photos

## Add your photos
Suggested names:
- `images/hero.jpg`
- `images/zones/master-digger.jpg`
- `images/zones/rc-tracker.jpg`
- `images/zones/einstein-table.jpg`
- `images/gallery/photo-1.jpg` through `photo-4.jpg`

The page currently uses placeholders so it works immediately. The placeholder blocks in `index.html` can later be changed to `<img>` elements pointing to your actual photos.

## Local preview
Open `index.html` in a browser, or use the VS Code Live Server extension.

## GitHub Pages
Push this folder to your GitHub repository and configure GitHub Pages to deploy from the `main` branch, root folder.
